# Archived planning documents

These are the original planning documents from March 2026, written for
"Claude Usage Monitor" before it became COG. They are kept as historical
reference and are **not** a description of the current app.

| Document | What it was |
|---|---|
| `01-background-research.md` | Investigation of what local Claude Desktop data was accessible on Windows |
| `02-architecture.md` | The original system architecture plan |
| `03-prd.md` | The 0.1 draft product requirements |
| `04-wireframes.md` | ASCII wireframes for the first set of views and widgets |

Where they differ from the code, the code wins. Known drift: they describe a
Windows-only app with an InfluxDB/Grafana sync. COG ships for Windows and Linux,
and Remote Sync is still a stub. For the current architecture, read
`.claude/CLAUDE.md` and the repo `README.md`.
